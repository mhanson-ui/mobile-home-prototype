# V2 Mobile Homepage Prototype - Ready for Review

Hi team,

I wanted to share the V2 Mobile Homepage prototype that's now ready for your review and feedback.

## Quick Context
We've built an interactive prototype that demonstrates 4 different approaches for organizing content on our mobile homepage. This directly addresses the "visual sameness" and content discovery issues we identified in V1.

## What's New
- **4 distinct approaches** to test different content organization strategies
- **Interactive genre filtering** - click any genre to instantly filter all content
- **Personalization system** - content adapts based on viewer type (TV, Movies, News, Sports, etc.)
- **Smart badge system** - cleaner visual hierarchy with LIVE/NEW badges and content tags
- **Live improvements** - proper separation of live events vs. channels

## How to Access
1. Go to [prototype URL]
2. Click "View V2 Prototype" 
3. Select your viewer type
4. Choose any of the 4 approaches to explore

## The 4 Approaches
1. **Intent-Based**: Fixed grouping by function (Utility → Live → Editorial)
2. **Mixed Aspect**: Visual differentiation through different card shapes
3. **Contextual**: Content changes position based on time of day
4. **Anchor + Rotational**: Fixed key rails with dynamic content below
